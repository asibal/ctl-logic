CTL-Logic

Based on CTL-1

CTL-Logic: use the M-VAVE FM-1 as Midi Controller for Logic Pro, Reaper, and other DAWs. Based on the CTL-1.

Try it in the browserThe same code the FM-1 runs, with sound. Mouse, touch or keyboard; in Chrome or Edge it can play your MIDI ports. Install v1.0From Chrome or Edge, with the FM-1 connected by USB. Nothing to install on the computer. SourceGitHub, MPL-2.0 / Built on CTL-1 by Charles Vestal / Built on fm1-base and felucca-bsp, from Felucca by Leo Kuroshita, Hügelton Instruments.
